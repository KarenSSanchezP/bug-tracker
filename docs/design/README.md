# Guía de Diseño UX/UI – TRIAGE

Este directorio contiene la guía de estilo y los mockups de las historias de usuario del sistema TRIAGE.

## Archivos

| Archivo | Descripción |
|---------|-------------|
| `guia-estilo.md` | Guía de estilo con paleta de colores, tipografía, componentes y reglas de diseño |
| `tokens.css` | Variables CSS (tokens de diseño) compartidas por los mockups |
| `hu1-crear-bug.html` | Mockup interactivo de la pantalla HU-1: Crear bug |
| `hu1-crear-bug-light.png` | Captura de pantalla HU-1 en tema claro |
| `hu1-crear-bug-dark.png` | Captura de pantalla HU-1 en tema oscuro |
| `hu2-listar-bugs.html` | Mockup interactivo de la pantalla HU-2: Listar bugs |
| `hu2-listar-bugs-light.png` | Captura de pantalla HU-2 en tema claro |
| `hu2-listar-bugs-dark.png` | Captura de pantalla HU-2 en tema oscuro |

## Cómo visualizar los mockups

Abre los archivos HTML directamente en tu navegador. Puedes alternar entre el tema claro y oscuro usando el parámetro `tema` en la URL:

- **Tema claro:** `hu1-crear-bug.html?tema=light`
- **Tema oscuro:** `hu1-crear-bug.html?tema=dark`

Lo mismo aplica para `hu2-listar-bugs.html`.
